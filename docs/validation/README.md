## إعادة إنتاج النتائج

```sh

./gradlew --no-daemon :app:lintRelease   # التقرير: app/build/reports/lint-results-release.txt
```

> الأرقام أعلاه تخصّ البناء المحلي في تلك اللحظة، وليست ضمانًا لسلوك الخدمة أو للجدولة على جهاز حقيقي.
